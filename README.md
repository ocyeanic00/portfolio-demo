# Asha — Student Portfolio

A multi-page personal portfolio built with vanilla HTML, CSS and JavaScript. No frameworks, no build tools — just open `index.html` in a browser.

## Pages

| File | Page |
|---|---|
| `index.html` | Home (landing) |
| `pages/about.html` | About |
| `pages/education.html` | Education |
| `pages/projects.html` | Projects |
| `pages/contact.html` | Contact |

## Structure

```
portfolio/
├── index.html
├── pages/
├── css/style.css
├── js/script.js
└── images/
```

## Features

- Editorial black & white design with warm off-white palette
- Dark / light mode (persisted via `localStorage`)
- Sticky navbar — logo left, links centered, toggle right
- Hero banner with portrait overlay
- Smooth scroll-reveal animations
- Project category filter
- Contact form with live validation
- Fully responsive — mobile hamburger menu included

## Run

Open `index.html` directly in any browser. No server or install needed.
